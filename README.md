# Profile Card Component

A small responsive profile-card UI exercise based on the Frontend Mentor profile card challenge. The page demonstrates a compact card layout, typography, profile details, and statistic styling using HTML and CSS.

## Tech stack

- HTML5
- CSS3
- Google Fonts
- Local image and icon assets

## Run locally

Open `index.html` in a browser, or use VS Code Live Server. Keep the stylesheet and `images/` directory in their existing relative locations.

## Status

This is a static front-end practice component. The sample profile information is demonstration content and should not be treated as a real person's verified profile.
